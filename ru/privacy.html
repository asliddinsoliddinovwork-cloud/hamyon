Политика конфиденциальности

Последнее обновление: 2026-11-11

Коротко

Hamyon не просит регистрацию, не использует рекламу и аналитику. Финансовые данные, которые вы вводите в приложение, хранятся только на вашем устройстве.

Какие данные хранит приложение

Ваше имя, счета, операции доходов и расходов, бюджет, долги и настройки. Всё это находится только в памяти телефона и не передаётся разработчику или третьим лицам.

Интернет

Приложение для Android работает без интернета. Файлы веб-приложения для iPhone загружаются с сайта hamyonapp.uz, и наличие новой версии проверяется на этом же сайте; введённые вами данные при этом не отправляются.

Резервная копия

Файл копии сохраняется туда, куда вы укажете. Где его хранить и кому передавать, решаете только вы.

PIN-код и биометрия

Проверку Face ID, Touch ID или отпечатка пальца выполняет сам телефон. Данные лица и отпечатка приложению не передаются.

Сайт

Сайт hamyonapp.uz размещён на GitHub Pages. Сайт не использует cookie, аналитику и рекламу; в браузере сохраняется только выбранная тема (светлая или тёмная). GitHub как хостинг-провайдер может фиксировать IP-адрес посетителя в технических журналах.

Удаление данных

Если удалить приложение или очистить данные сайта на iPhone, все записи будут удалены. Поэтому сначала сделайте резервную копию.
